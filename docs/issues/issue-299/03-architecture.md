# Phase 3 — Architecture: relocate font `@import`

> Issue: [#299](https://github.com/guardiatechnology/design-system/issues/299)

## Affected components

| Component | Type | Change | AC |
|---|---|---|---|
| `ui_kit/styles/index.css` | Stylesheet (source of truth) | Move the font `@import url(...)` from below `@source`/`@custom-variant` to immediately after `@import "tw-animate-css"`. | AC-1, AC-2 |
| `dist/styles/index.css` | Build artifact | Regenerated by `npm run build` (verbatim copy per `rslib.config.ts:19-24`). Not edited by hand. | AC-4 |
| `ui_kit/styles/index.css.test.ts` (new) | Vitest unit test | Asserts the `@import` ordering invariant against the source CSS. | AC-3 |
| `scripts/push-baselines.mjs` | CI tooling (regenerate-baselines flow) | Pace blob creation (small chunks + inter-chunk delay) and retry on GitHub secondary rate limits (403/429), honoring `Retry-After`. Lets the 214-baseline regenerate push succeed. | AC-5 |

## CI tooling fix (AC-5)

`push-baselines.mjs` creates one Git Database blob per changed baseline to keep the server-signed commit (`lex-signed-commits`). Binary PNGs cannot be inlined in a tree, so the 214 blob POSTs are unavoidable; the fix is to **pace** them (`CHUNK_SIZE=3`, `CHUNK_DELAY_MS=1200`) and **retry with backoff** on secondary-rate-limit responses rather than reduce their count. The signed-commit design is unchanged.

## Approach

The font block comment (lines 23–28) documents *why* the fonts are loaded (Poppins UI, Roboto fallback, Lastica note). It moves up together with the `@import` line so the rationale stays attached to the declaration. The result:

```css
@import "tailwindcss";
@import "tw-animate-css";

/* Fontes. Poppins + Roboto via Google Fonts CDN. Lastica … (comment preserved) */
@import url("https://fonts.googleapis.com/css2?family=Poppins:…&family=Roboto:…&display=swap");

@source "../components/**/*.{ts,tsx}";
@source "../theme/**/*.{ts,tsx}";
@custom-variant dark (…);
```

This satisfies the CSS `@import`-ordering rule in every bundler (Turbopack hard error → resolved; lightningcss warning → resolved).

## Design decisions

- **No ADR.** This is a spec-conformance bug fix that preserves existing behavior (same fonts, same CDN). It introduces no new architectural choice. The "self-host fonts" alternative is deferred (see 02-requirements § Out of scope); if pursued later it would warrant its own issue + ADR.
- **Test level.** A unit test reading the source file is sufficient and deterministic — no need for a build-integration or visual-regression test. Visual baselines (Ubuntu/CI SoT) are untouched.

## Risk

- Minimal. Pure reordering of `@import` statements; no selector, token, or cascade change. Font resolution order in `@theme inline` (`--font-sans: "Poppins", "Roboto", …`) is unaffected — that is independent of the `@import` position.
- Lexis check: no impact on `lex-brand-typography` (Poppins/Roboto/Lastica preserved), `lex-brand-colors`, or `lex-design-system-library`.
